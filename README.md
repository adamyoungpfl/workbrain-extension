# Workbrain

A Chrome side panel that builds and maintains a personal context file for use with AI assistants.
No account, no server, nothing transmitted.

**Start here:** [`HANDOFF.md`](./HANDOFF.md) · **Working in this repo:** [`CLAUDE.md`](./CLAUDE.md)

```bash
npm install
npm run build     # -> dist/
npm run check     # the gate: typecheck, unit, build, e2e, a11y
```

Load unpacked: `chrome://extensions` → Developer mode → Load unpacked → `dist/`
